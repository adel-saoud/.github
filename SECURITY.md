# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately, never in a public issue, pull request or
discussion.

1. Open the **Security** tab of the affected repository.
2. Click **Report a vulnerability**.
3. Describe the issue, the affected version and the steps to reproduce it.

The report is visible only to you and the maintainer. If the button is missing, open a
public issue that says only "security report, please enable private reporting", with no
details, and I will switch it on.

## Supported versions

Only the latest minor release of each project gets security fixes. Older versions are
not patched; upgrade to the latest release first.

## What to expect

These projects have one maintainer, working on them in spare time.

- Acknowledgement within 7 days.
- A first assessment (confirmed or not, and how severe) within 14 days.
- For confirmed issues, a fix or a mitigation as soon as I can, released as a patch
  version and announced in a GitHub security advisory. You are credited in the
  advisory unless you prefer not to be.

Please give me a reasonable time to ship a fix before you disclose publicly. I will keep
you updated in the private report thread.
